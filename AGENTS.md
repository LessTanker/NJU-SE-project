# Git Commit Rules

- Commit only task-related changes; review the staged diff before committing.
- Use this commit message format: `<Time> <Specific changes> <Committer>`.
- Use the actual commit time in Beijing.
- Always use English in commit message.
- Describe the concrete changes concisely and append the committing agent's name in angle brackets.
- Example: `2026-10-18 14:30:00 Clarify API error handling <Codex>`.
